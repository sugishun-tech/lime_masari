# ライムとマサリのゆったり解説

## ラングランズ・プログラム：点を数えるところから

完成動画は別添の `langlands_lime_masari_voiced.mp4`。音声入り。視聴にPython、Docker、VOICEVOXや音声サーバーの起動は不要。

1920×1080、30fps、約11分29秒。28場面、84発話。ライムとマサリを全編に配置し、音量に応じた口パクとまばたきを付けた。キャラクターのアニメーションは15fpsで更新する。BGMは使用していない。

## 今回の差し替え

番組名は「ライムとマサリのゆったり解説」。画像は本動画向けに新規生成したキャラクターに置き換えた。既存キャラクターの立ち絵は同梱・使用していない。自己紹介・エンディング・変更した台詞の音声も再生成し、字幕、名札、クレジット、MP4のメタデータを新しい名前に統一した。数学の説明内容と参考資料は維持した。

## 音声と数式

eSpeakの音素入力を使い、二人別々の合成設定で音声を作成した。今回の二人の設定名は `LimeFormant` と `MasariFormant`。特定の実在人物の声をクローンしたものではない。

数式は画面用の画像、字幕は日本語文章、音声合成への入力は手動指定のかな読みとして分離した。英字、数字、LaTeXや数学記号を合成器へ直接渡していない。84発話分の収録済みWAVを同梱している。数式を一文字ずつ音読するのではなく、主に操作や意味を日本語で説明する。

音声・字幕の時刻と口パクは、同梱WAVの実測長と波形に基づく。音素ごとの精密な口形再現ではない。全編を実際に聴いての発音・アクセント・聞き取りやすさの確認は行っていない。

## ファイル

- `script.md`：名前付き台本とかな読み。
- `subtitles.srt`：実測音声長に同期した字幕。MP4には焼き込み字幕と選択可能な日本語字幕トラックも入れてある。
- `data/scenes.json`：数式・画面構成・資料番号。
- `data/dialogue.tsv`：場面・話者・表情タグ・字幕・かな読み。区切り文字は `|`。
- `data/cues.json`、`data/timeline.json`：音素列、時間、波形から決めた口の状態。
- `audio/`：84発話の収録済み音声。再編集時にはこれらから通し音声を再構成する。
- `assets/characters/`：透過PNG、口の開閉とまばたき用の画像。
- `assets/source_sheets/`：新規画像生成の元シート。
- `assets/formulas/`：数式画像とLaTeXソース。
- `src/`：動画生成・音声処理・数値検証のPythonソース。
- `QA.md`、`checks/`：実施した検査と限界。
- `references.md`、`CREDITS.md`：数学資料と制作情報。

フォントファイル、合成エンジン本体、外部のキャラクター素材パックは同梱していない。

## 再編集する場合のみ

完成MP4の視聴には以下の操作は不要。

同梱WAVと数式画像を使う動画の再生成は、Python、FFmpeg、Pillow、NumPy、日本語フォントがある環境で、プロジェクトのフォルダから実行する。

```bash
python src/render_video.py
```

通常の再生成では音声合成サーバーへ接続しない。出力先はプロジェクトの一つ上のフォルダ。音声を変更するときだけeSpeakとSciPy、数式画像を作り直すときだけLaTeXとdvipngが必要。

画像差分は元シートから切り出し、髪や衣装を固定して目と口の部分だけを差し替えている。動画の口は開閉の二状態。台本に残した表情タグは編集用で、全タグに独立した表情画像があるという意味ではない。
